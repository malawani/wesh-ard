# المراجعة التحريرية المحلية — غير مكتملة

طلب المراجعة الأصلي منع النشر. أذن المستخدم لاحقًا صراحة بحفظ الإصدار السابق ورفع التغييرات الجديدة ونشرها. راجع `DEPLOYMENT.md`؛ الإذن الجديد لا يعني اكتمال المراجعة التحريرية.

## الحالة المحفوظة

حصر المحتوى: 2602 سجلًا في 320 موقفًا و12 مسارًا، تشمل سجلين محفوظين خارج الاقتراحات. اكتملت مراجعة 197 سجلًا بشرح خاص من أربعة حقول لكل سجل؛ أُبقي 191 نصًا، وعُدلت 6 نصوص، وصُحح تصنيف 6 سجلات. يتقاطع تصحيح التصنيف مع قرار الإبقاء أو التعديل. بقيت 2405 سجلات؛ لا تمثل هذه النسخة إتمامًا لمعايير قبول المهمة.

- `INVENTORY.md`: مصادر المحتوى والحصر الفعلي.
- `../../content/editorial/baseline.json`: لقطة المصدر قبل هذه المهمة؛ لا تستبدلها عند استئناف المراجعة.
- `../../content/editorial/batches/`: قرارات المراجعة والشروح المكتوبة لكل عبارة.
- `../../content/editorial/progress.json`: جميع المعرّفات المكتملة والمتبقية والدفعة التالية.
- `../../reports/editorial/review-log.json`: النص السابق والنهائي وأسباب تعديل النص أو التصنيف.
- `REQUEST.txt`: الطلب المعتمد كاملًا.

## استئناف العمل

ابدأ بالمعرّفات في `nextBatch`، وأولها `misunderstand:soft:0`. اقرأ العبارة مع سياق موقفها وتصنيفاتها، ثم اكتب قرارًا وشروحًا مستقلة في دفعة جديدة. لا تولّد الشروح بقالب، ولا تعدّ التحقق الآلي مراجعة لغوية. سجّل كل تعديل على النص أو التصنيف مع سببه، وحافظ على المعرّفات والروابط والأعداد. أضف الدفعة إلى `content/editorial/index.ts` ثم شغّل `npm run validate:editorial` لتحديث التقدم والسجل.

## العرض والبيانات الشخصية

يعرض `components/phrase-analysis.tsx` قسم «المعنى والأثر» في بطاقات النتائج والمفضلة، مع عناوين الحقول الأربعة. يرتبط الشرح بالنص النهائي المطابق تمامًا. تظل النسخ القديمة والنصوص الخاصة كما حفظها المستخدم، ويُعرض غياب الشرح بوضوح دون اختلاق تفسير. لا تتغير مفاتيح التخزين ولا تُمسح البيانات. تتيح هوية المفضلة المكونة من المعرّف والنص حفظ النسخة القديمة والجديدة معًا.

## التحقق

`npm run validate:editorial` يفحص سلامة المنجز ويعرض التغطية الحقيقية. أما `npm run validate:editorial:complete` فيشترط مراجعة جميع السجلات، ويجب أن يفشل حاليًا لأن 2405 سجلات لم تُراجع. فحص اكتمال المحتوى القديم `validate:release` لا يثبت اكتمال هذه المراجعة.

شغّل البناء قبل فحص الأنواع، لأن Next يعيد إنشاء `.next/types`؛ لا تشغلهما بالتوازي. اختبارات الواجهة تستخدم البناء الثابت المحلي ولا تنشره.
