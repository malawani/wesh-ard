# التوجيه الحالي لاستكمال المراجعة

التوجيه الأحدث الصريح للمستخدم في 17 نوفمبر 2026:

> اكمل المراجعه هنا في الشات جي بي تي ثم ارفعهم جميعادفعة وحدة

تستمر مراجعة المحتوى وكتابة الشروح داخل مساحة العمل، مع حفظ الدفعات والتقدم محليًا. لا يُدفع أي تحديث جزئي ولا يُنشر ولا تُنشأ فروع بعيدة قبل اكتمال جميع العبارات المعتمدة. بعد اكتمالها واجتياز الفحوص يُنفذ الرفع دفعة واحدة. لا يطلب اعتماد منفصل عند كل دفعة مراجعة محلية.

النطاق ثابت: 2602 عبارة في 320 موقفًا و12 مسارًا، دون إضافة أو حذف أو دمج سجلات. يحافظ العمل على النصوص الشخصية والمفضلة القديمة. تظل النسخة السابقة المحفوظة على GitHub متاحة. لا تُفسر طلبات النشر السابقة بوصفها إذنًا برفع دفعة جزئية جديدة بعد هذا التوجيه.

أصبح سير GitHub Pages يشترط `validate:editorial:complete` قبل النشر، حتى لا يكفي اجتياز فحص سلامة دفعة جزئية. كان هذا الشرط يفشل أثناء التغطية الجزئية، وأصبح يجتاز في 25 نوفمبر 2026 بعد اكتمال 2602 سجلًا وصحة جميع الشروح. لم تُرفع دفعات الاستكمال الجزئية؛ الرفع النهائي مجمع بعد التحقق.
