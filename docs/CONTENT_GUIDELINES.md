# قواعد تحرير المحتوى

هذه قواعد تنفيذ مستمدة من المواصفات المعتمدة وليست المقترحات الإضافية.

- معرّف canonical واحد للموقف، والربط بمسار آخر لا يزيد الأعداد.
- ثماني عبارات مستقلة على الأقل لكل موقف؛ لا زيادة للأعداد بتغيير كلمة أو مبالغة فقط.
- مراجعة سعوديّة طبيعية دون خلط عشوائي لصيغ إقليمية.
- نصوص واجهة مفهومة، وعبارات محادثة أخف، دون تحويل صرفي آلي للمخاطب.
- لكل عبارة نبرات فعلية ومراحل مسموحة ودرجة جرأة وطول محسوب.
- عبارات الاعتذار تتحمل المسؤولية؛ طلب المساحة والرفض لا يتضمنان ضغطًا.
- لا تشخيص للطرف الآخر، ولا افتراض أن تأخر الرد دليل رفض.
- الحفاظ على المصدر القديم لا يعني إقرار جودته التحريرية؛ تُراجع المواضع القديمة الحساسة قبل الإطلاق الكامل.
- تشغيل validate:content بعد كل دفعة؛ الفحص الآلي يكشف التطابق وبعض التشابه، ولا يغني عن مراجعة المعنى.
- التشابه الأصلي بين miss:direct:0 وmissing:direct:0 مُراجع: الأول رد على رسالة شوق، والثاني مبادرة. لم نضف النص نفسه إلى سجل جديد.
