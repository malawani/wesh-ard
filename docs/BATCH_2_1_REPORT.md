## التحقق

- npm test: 47 ناجحة، وتشمل اختبارات المحافظة على المصدر والترحيل والحذف وعدم عودة المحذوفات والأطوال وحدود المراحل والجرأة والبحث.
- npm run validate:content: ناجح، بلا تكرار مطابق أو معرّفات مفقودة. تحذير تشابه أصلي واحد موثق.
- npm run typecheck: ناجح.
- npm run build: ناجح.
- Playwright: 8 ناجحة على الكمبيوتر والجوال. تتضمن الرحلة الأصلية وموقفًا جديدًا يتبدل فيه الرد بين الزواج وأول تواصل، والنسخ الفعلي للحافظة وحفظ المفضلة بعد التحديث وحالة منع التخزين.
- فحص بصري للقطة الجوال: RTL سليم، النصوص والبطاقات واضحة دون قص أفقي في الحالة المعروضة. لقطتا desktop وmobile في reports/.
- npm run validate:release: فشل متوقع وصحيح؛ لا يوجد ادعاء باكتمال الإصدار. التقرير منفصل في reports/release-validation.json ولا يغيّر تقرير التقدم المرحلي.
