# وش أرد؟ — تطوير V2 جارٍ

مساعد عربي لاختيار رسائل وردود سعودية من مكتبة محلية. يحتفظ بالمشروع الأصلي ومعرّفات المفضلة. هذه نسخة مرحلية، وليست التوسعة النهائية.

## الحالة الفعلية

- أنجزت المرحلة صفر، والمرحلة الأولى، والدفعة الأولى من المرحلة الثانية.
- 40 موقفًا مكتوبًا و356 عبارة فريدة بعد تطبيع الحروف والمسافات والتشكيل.
- تضم 180 عبارة أساسية و36 نسخة قديمة مخصصة للمراحل و140 عبارة جديدة.
- 3 مسارات متاحة حاليًا. سجل المواقف المطلوب يصف 12 مسارًا و320 موقفًا، ولا يحتسب المواقف غير المكتوبة.
- 9 مراحل علاقة و12 نبرة ذات محتوى فعلي، و3 درجات جرأة، مع تصنيف فعلي للطول. النبرات المتاحة تختلف حسب الموقف والمرحلة.
- لا تسجيل دخول أو قاعدة بيانات أو AI API أو ربط بمحادثات خارجية.
- راجع docs/CONTENT_PROGRESS.md وcontent/progress.json للأعداد المستخرجة من البيانات.

## التشغيل والفحص

Node.js 20.19 أو أحدث وnpm:

```sh
npm ci
npm run dev
```

ثم افتح http://localhost:3000.

```sh
npm run typecheck
npm test
npm run validate:content
npm run build
npm run start
```

فحص اكتمال الإصدار النهائي مختلف عن فحص الدفعات، وسيفشل حاليًا لأن التوسعة غير مكتملة:

```sh
npm run validate:release
```

اختبارات المتصفح:

```sh
npx playwright install chromium
npm run build
npm run test:e2e
```

في بيئة هذه الجلسة مسار التخزين الافتراضي في المنزل غير قابل للكتابة. الأوامر التي استُخدمت بدلًا منه:

```sh
npm ci --cache /workspace/work/npm-cache
PLAYWRIGHT_BROWSERS_PATH=/workspace/work/playwright-browsers npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/workspace/work/playwright-browsers npm run test:e2e
```

## البنية

- content/legacy: المصدر القديم، صيغ المراحل ومعرّفاتها، وإضافات المواقف القديمة.
- content/manifest.ts: قائمة المواقف المطلوبة الـ320، منفصلة عن المحتوى المنفذ.
- content/routes: دفعات المواقف الجديدة، ثماني عبارات لكل موقف على الأقل.
- content/schemas: الأنواع والمراحل والنبرات والأطوال.
- lib/recommendation: الترشيح، البدائل المقيدة بالمرحلة والجرأة، ومنع تكرار النصوص في النتائج.
- lib/search: التطبيع والمرادفات والترتيب المحلي.
- lib/storage وlib/migration: حفظ المفضلة وترحيل البيانات القديمة.
- lib/validation وscripts: تحقق المحتوى وتقارير التقدم.
- tests: اختبارات المصدر القديم، V2، والمتصفح على الكمبيوتر والجوال.

## إضافة دفعة محتوى

1. اختر 10–12 موقفًا من remainingSituations في التقرير، بمعرّفات manifest نفسها.
2. اكتب عبارات مختلفة فعلًا وأهلية مراحل واضحة لكل عبارة، مع advice وavoid.
3. أضف الدفعة إلى content/index.ts. لا تنسخ سجلًا كاملًا إلى مسار آخر لزيادة العدد.
4. شغّل فحص المحتوى والاختبارات والأنواع والبناء. راجع تحذيرات التشابه يدويًا.
5. تحقق من تغير النتائج مع المرحلة والنبرة والطول والجرأة، وحدّث اختبارات المتصفح للحالات الجديدة.
6. احفظ نقطة رجوع وحدّث تقرير الدفعة.

## الخصوصية والتوافق

تعمل المطابقة داخل المتصفح؛ لا تحفظ نصوص البحث. تُنقل المفضلة إلى wesh-ard:v2:favorites مع الحفاظ على المصادر القديمة. بعد نجاح النقل لا نعيد استيراد المحذوفات في كل تحميل. العبارات غير المطابقة تبقى بنصها قابلة للنسخ والحذف. راجع docs/MIGRATION.md، خصوصًا حدود الرجوع للكود القديم واختلاف عناوين الاستضافة.

## النشر والتراجع

يُنتج البناء out/ صالحًا للاستضافة الثابتة. إعدادات GitHub Pages وSites الأصلية محفوظة. لم ننشر أو نغير إعدادات الموقع العام. النشر الحالي يتضمن فحصًا مرحليًا للمحتوى؛ قبل إصدار V2 النهائي يجب اعتماد validate:release وتجربة staging والمفضلة القديمة والجوال.

Git المحلي يحفظ الأصل عند ad5e02a ونقطة المرحلة الأولى عند الوسم phase-1-verified. لا تحذف بيانات المتصفح عند الرجوع. احتفظ بنسخة من بيانات V2؛ الكود القديم لا يقرأ الإضافات التي حُفظت في المفتاح الجديد.

## ما لم يكتمل

280 موقفًا، إكمال محتوى المسارات التسعة وإظهارها، أسئلة السياق، واجهة التقييم والبدائل وملف التفضيلات، مراجعة تحريرية شاملة، اختبار staging، وشروط الإطلاق النهائي. لا تُقدَّم النسخة الحالية على أنها V2 كاملة.

مقترحات المنتج والتواصل النفسي واللهجة موجودة منفصلة في docs/PROPOSALS_NOT_IMPLEMENTED.md ولم تنفذ.
