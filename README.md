# وش أرد؟ — Expansion V2

الموقع المنشور: **https://malawani.github.io/wesh-ard/**

تم النشر والتحقق من الموقع الحي في 17 نوفمبر 2026؛ تقريره في docs/DEPLOYMENT.md.

الدفعة المحلية الحالية من «المعنى والأثر»: 658 عبارة مشروحة من أصل 2602؛ المراجعة الشاملة غير مكتملة، والمتبقي 1944. سجل التغطية في `content/editorial/progress.json`. تعليمات حفظ النسخة السابقة والعودة إليها في `docs/editorial/DEPLOYMENT.md`. الموقع المنشور ما زال عند دفعة 197 عبارة؛ دفعة 658 لم تُرفع بعد.

موقع عربي لاختيار عبارات سعودية للمواقف الاجتماعية والعاطفية، مبني على المشروع الأصلي باستخدام Next.js App Router وReact وTypeScript strict. المطابقة محلية بلا AI API أو حسابات أو قاعدة بيانات مستخدمين.

## النسخة الحالية

- 12 مسارًا، 320 موقفًا مكتوبًا، و2600 عبارة قابلة للترشيح وفريدة بعد التطبيع.
- 2602 سجل عبارة إجمالًا؛ منها اعتذاران قديمان محفوظان للمفضلة والتوافق فقط ولا يُرشحان ولا يدخلان عدد الـ2600.
- جميع النصوص الأساسية الأصلية الـ180 ومعرّفات النتائج القديمة محفوظة، بما فيها 36 صيغة بحسب المرحلة.
- 9 مراحل علاقة، 12 نبرة، 3 درجات جرأة، وطول محسوب فعليًا لكل عبارة.
- بحث عربي محلي، نسخ، مفضلة وترحيل، أسئلة سياق لبعض المواقف، ملف تفضيلات، تقييمات وبدائل تعمل.
- تحقق من الأعداد الحالية عبر npm run validate:release وreports/release-validation.json؛ لا يُحتسب manifest وحده محتوى.

## التشغيل

يتطلب Node.js 20.19 أو أحدث وnpm:

```sh
npm ci
npm run dev
```

افتح http://localhost:3000.

```sh
npm run typecheck
npm test
npm run validate:content
npm run validate:release
npm run build
npm run start
```

البناء ثابت إلى out/. يعرضه start على المنفذ 3000. لا يرسل التطبيق الرسائل للآخرين؛ النسخ إجراء يختاره المستخدم.

## اختبارات المتصفح

```sh
npx playwright install chromium
npm run build
npm run test:e2e
```

الاختبارات تعمل على Chromium بوضعي الكمبيوتر والجوال، وتغطي جميع المسارات والنسخ الفعلي والحفظ والتحديث والترحيل ومنع التخزين والبحث وأسئلة السياق والتفضيلات والتقييمات والبدائل والخصوصية والتنقل ولوحة المفاتيح.

في بيئة هذه الجلسة استُخدمت مسارات كتابة محلية بدل المنزل:

```sh
npm ci --cache /workspace/work/npm-cache
PLAYWRIGHT_BROWSERS_PATH=/workspace/work/playwright-browsers npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/workspace/work/playwright-browsers npm run test:e2e
```

## بنية المشروع

- content/manifest.ts: معرّفات وعناوين المواقف الـ320 المعتمدة.
- content/routes: دفعات محتوى مكتوبة؛ الدوال المساعدة تضيف البيانات الوصفية ولا تولد الجمل من قوالب.
- content/legacy: المصدر القديم ومعرّفاته ونصوصه وإضافاته وخيارات تصرف الإرشاد.
- content/context.ts: أسئلة السياق، ربط الاختيارات بالعبارات، والبدائل التحريرية للاعتذارين القديمين.
- content/schemas: أنواع المسارات والمراحل والنبرات والجرأة والطول.
- lib/recommendation: الأهلية والترشيح والبدائل المحدودة والتقييمات.
- lib/search: تطبيع العربية والمرادفات السعودية والأوزان.
- lib/storage وlib/migration: حفظ المفضلة والترحيل والتفضيلات والتقييمات.
- lib/validation وscripts: فحص المحتوى وإنتاج التقارير والتقدم.
- components: الرئيسية والرحلة والنتائج والمفضلة وملف الكلام.
- tests: اختبارات الوحدة والترحيل والمحتوى والمتصفح.

## الترشيح والخصوصية

تُطبّق حدود المرحلة أولًا، ثم حساسية الموقف والسياق والنبرة والجرأة والطول. بدائل النبرة والطول لا ترفع الجرأة أو تتجاوز المرحلة. تفضيل تقليل المبالغة يستبعد الدرجة الثالثة. المواقف الحساسة لا تعرض نبرات رومانسية غير مناسبة.

عند اختيار سياق مثل إلغاء موعد، تُقدَّم العبارة الخاصة بالسبب على اعتذار عام، مع تفسير أي بديل للنبرة. «رؤية بديل مناسب» يبدل البطاقة بعبارة أخرى مؤهلة؛ لا يغير القيود لتوفير بديل.

التقييمات في الجلسة افتراضيًا. حفظها بين الزيارات اختياري من «ملفي في الكلام»، وتؤثر في الترتيب بعد تقييم ثلاث عبارات مختلفة. نص البحث والسياق الحر لا يُحفظان. لا مزامنة بين الأجهزة أو عناوين الاستضافة. راجع صفحة الخصوصية وdocs/MIGRATION.md.

## إضافة محتوى أو تعديله

1. احتفظ بالمعرّفات والنصوص القديمة؛ لا تستبدل نص مفضلة منشور بمعنى آخر تحت المعرّف نفسه.
2. عدّل manifest فقط بقرار منتج واضح. المسارات الإضافية لنفس الموقف تُربط بـrelatedRoutes ولا تُضاعف السجل.
3. اكتب ثماني عبارات مناسبة وفريدة على الأقل، وأهلية مراحل ونبرات ودرجة جرأة وطول حقيقيين.
4. شغّل فحوص الأنواع والوحدة والمحتوى والإصدار والبناء والمتصفح.
5. راجع التشابه تحريريًا؛ الفحص الآلي لا يثبت وحده اختلاف المعنى أو جودة اللهجة.
6. حدّث وثائق التسليم واحفظ نقطة رجوع.

## النشر والتراجع

نُشرت النسخة على GitHub Pages بإذن المستخدم بعد معاينة محلية بمسار /wesh-ard/. نجحت الاختبارات على الموقع المنشور، بما فيها المسارات الـ12 والمفضلة والنسخ والتفضيلات. لم يُنشأ نطاق staging مستقل. قبل أي إصدار جديد، راجع أثر basePath ونطاق localStorage واختبر النسخة المناسبة.

Git المحلي يحتوي المصدر الأصلي عند ad5e02a ونقاط الدفعات؛ استخدم الوسم v2-local-verified للنسخة المختبرة النهائية. الرجوع إلى V1 لا يحذف بيانات المتصفح لكنه لا يقرأ إضافات مفتاح V2. راجع docs/FINAL_HANDOFF.md لخطة التراجع.
