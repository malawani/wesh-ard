# وش أرد؟

مساعد عربي لاختيار الكلام المناسب للمواقف العاطفية والاجتماعية. يختار المستخدم المسار، ثم الموقف ومرحلة العلاقة ونبرة الكلام، ويحصل على عبارات سعودية جاهزة للنسخ والحفظ.

## التشغيل

يتطلب Node.js 20.19 أو أحدث وnpm. لتشغيل التطوير من مجلد المشروع:

```sh
npm install
npm run dev
```

افتح [localhost:3000](http://localhost:3000).

```sh
npm run typecheck
npm test
npm run build
npm run start
```

يبني Next.js نسخة ثابتة في `out/` ويعرضها أمر `start` على المنفذ 3000. يستخدم Sites إعداد `.openai/hosting.json` لنشر المجلد نفسه. يمكن نشر `out/` على استضافة ثابتة تدعم عرض `index.html` لكل مجلد.

## النشر على GitHub Pages

1. ارفع محتويات مجلد المشروع إلى الفرع `main` في جذر مستودع GitHub، بما فيها `.github/workflows/pages.yml`.
2. من إعدادات المستودع افتح **Settings → Pages**، ثم اختر **GitHub Actions** في **Source**.
3. من تبويب **Actions** شغّل **Publish Wesh Ard** على الفرع `main`. بعد نجاح النشر، افتح الرابط المعروض في صفحة **Settings → Pages**. كل رفع لاحق إلى `main` يشغّل البناء والنشر تلقائيًا.

المسار المعتاد لهذا المستودع هو `https://malawani.github.io/wesh-ard/`. يستخدم البناء المسار الذي تعيده إعدادات Pages تلقائيًا، بما في ذلك النشر على نطاق مخصص. تعرض Pages الموقع على الإنترنت بعد النشر. يتطلب النشر من مستودع خاص على حساب شخصي خطة GitHub Pro.

## البنية

| المسار | المسؤولية |
| --- | --- |
| `app/` | الدخول، الهوية البصرية، صفحات التعريف والخصوصية وحالة 404 |
| `components/` | المسارات، اختيار الموقف والأسلوب، النتائج، النسخ والمفضلة |
| `lib/catalog.ts` | المكتبة الأصلية كاملة، 30 موقفًا و180 عبارة |
| `lib/engine.ts` | تطبيع العربية، البحث المحلي، وتخصيص العبارات بحسب المرحلة والنبرة |
| `lib/favorites.ts` | قراءة المفضلة، التحقق منها، ومنع تكرار العبارات |
| `tests/engine.test.ts` | اختبارات المكتبة والبحث والنبرات ومرحلة العلاقة والمفضلة |
| `.github/workflows/pages.yml` | فحص الأنواع واختبار المشروع وبناؤه ونشره على GitHub Pages |

## الخصوصية

تتم مطابقة النصوص داخل المتصفح. يحتفظ التطبيق بعبارات المفضلة في `localStorage` إذا أتاحه المتصفح. تبقى نصوص البحث في ذاكرة الصفحة خلال الاستخدام. تحمَّل الخطوط من ملفات التطبيق.

## خطوات المرحلة التالية

- تجربة اللهجة والعبارات مع مستخدمين من مناطق سعودية مختلفة ومراجعة الحالات التي تتكرر فيها النتائج غير المطابقة.
- إضافة اختبارات متصفح تلقائية لرحلة الاختيار والنسخ والحفظ، على الهاتف والكمبيوتر.
- إضافة خيارات إعادة صياغة محددة، مثل الاختصار أو الصياغة الألطف، وفق نتائج تجربة المستخدمين.
